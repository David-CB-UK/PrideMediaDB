# PrideMediaDB

A full-stack Django application for exploring LGBTQ+ film and media, with searchable film data, representation information, ratings and reviews.

## Project status

PrideMediaDB is being developed as **Project 3 (PP3)** using an Agile approach.

The project backlog is maintained through GitHub Issues using user stories, acceptance criteria, implementation tasks and MoSCoW prioritisation.

### Current planning priorities

- **Must:** assessment-critical functionality and core application features
- **Should:** significant enhancements that add value but are not essential to the core application
- **Could:** desirable features that can be implemented if time and effort allow
- **Won't:** features considered but deliberately outside the current project scope

The current PP3 baseline is **30 estimated effort points**:

- Must: 18 (60%)
- Should: 6 (20%)
- Could: 6 (20%)

## Development approach

The project will use:

- Git and GitHub for version control and development history
- GitHub Issues for user stories, acceptance criteria and tasks
- Agile iterative development
- **Test Driven Development (TDD) using the Test → Code → Refactor cycle**
- Django and Python for the full-stack application
- A relational database for persistent application data
- Bootstrap and responsive front-end development
- Secure cloud deployment

TDD is a core Project 3 requirement. Applicable functionality will be developed by writing a failing automated test first, implementing the minimum code required to make it pass, and then refactoring while keeping the tests passing. Meaningful commits will be used to demonstrate this development process.

The development history is intentionally maintained through small, descriptive commits so that each feature or fix can be traced through the project.

## Core PP3 scope

The application will provide a relational LGBTQ+ film/media database with:

- film and media records, including short films
- genres, themes, categories and LGBTQ+ representation
- age ratings
- languages and English-subtitle information
- collections and series
- search and browsing
- user accounts and permissions
- Watchlist and watched status
- user film suggestions requiring administrator approval
- ratings and reviews
- administrator data management
- artwork and relevant external media references

The project will also plan for external film-data enrichment without making Plex a Project 3 dependency.
